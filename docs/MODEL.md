# Initial target simulation model

This is an **unfitted mechanistic prototype for designing computational experiments**. It does not predict tumor survival, normal-tissue growth, muscle mass, kidney function or clinical benefit. No drug-specific response data were supplied in the completed pilot.

The local phenotype and allele files determine the hypotheses and endpoint definitions. They do not estimate the kinetic parameters. The full frozen policy and ranges are in [frozen policy](../config/target_first_framework.json), and every sampled parameter set is in the parameter designs generated by the full target runner.

Four protein pools are represented: reference protein, full-length missense protein, truncated protein, and readthrough protein. For each pool:

`dP/dt = synthesis − degradation × P`

After a step intervention, the exact solution is:

`P(t) = synthesis/degradation + (P(0) − synthesis/degradation) × exp(−degradation × t)`

Each pool starts at its scenario's untreated steady state. A reference allele supplies 0.5 normalized synthesis units and has degradation rate 1; two reference alleles would give one total reference-protein unit. Time is measured in reference-protein mean lifetimes, not hours.

Checkpoint-equivalent and attachment-equivalent BUBR1 are computed separately:

`B_checkpoint = Σ protein_amount × checkpoint_function_per_molecule`

`B_attachment = Σ protein_amount × attachment_function_per_molecule`

Functional fractions are sampled assumptions between zero and one, with ranges defined for each scenario. Total protein can rise while useful function remains unchanged.

| Allele scenario | Representation |
| --- | --- |
| Trans, unstable residual missense | One missense pool with faster degradation; one stop-bearing transcript with uncertain survival |
| Trans, stable dysfunctional missense | Approximately reference turnover but low intrinsic checkpoint and attachment function |
| Trans, stable partly functional missense | Approximately reference turnover and greater retained intrinsic function |
| Cis with a reference allele | One reference pool; the other transcript carries both changes. Its readthrough product retains the missense change |

For the cis readthrough product, functional fractions multiply the assumed readthrough and missense fractions, and degradation is the larger of their assumed rates. This is a deliberately explicit approximation, not an experimentally estimated epistasis model. The cis scenario also changes the causal interpretation of the genotype.

The virtual interventions are:

| Intervention | Model operation |
| --- | --- |
| Vehicle | No parameter change |
| Residual stabilization | Reduce protein degradation by the intervention fraction times an uncertain responsive fraction |
| Residual function restoration | Move missense functional fractions toward one, without changing abundance or supplying absent protein |
| NMD attenuation | Increase the surviving stop-transcript fraction toward one |
| Readthrough | Redistribute a fraction of translation from truncated to readthrough product; total translation is conserved |
| Local PP2A bypass | Move local attachment-associated phosphatase capacity toward a reference value, without restoring checkpoint-equivalent BUBR1 |
| Aurora B reduction | Reduce kinase activity relative to local phosphatase capacity |
| APC/C-CDC20 reduction | Reduce an abstract exit-capacity parameter |
| BUBR1 suppression | Reduce synthesis of all BUBR1 pools; a mechanistic control |
| Reference-protein addback | Add reference synthesis; a positive control, not a nominated medicine |

Stabilization acts on all present pools. It does not require or assume mutant-selective drug action. Readthrough does not feed back on NMD in this version. NMD perturbation's effects on other transcripts, translation errors elsewhere, dominant-negative protein effects and proteotoxicity of accumulated products are omitted.

The attachment proxy uses a normalized kinase/phosphatase ratio:

`A = Aurora activity; Q = local PP2A proxy`

`attachment_balance_proxy = exp(−width × [ln(A/Q)]²)`

The proxy is set to zero when either activity is zero. Its optimum at A/Q = 1 and its width are analyst-selected assumptions inspired by the need for kinase/phosphatase balance. It is **not** a measured chromosome-alignment probability. Q is initially proportional to attachment-equivalent BUBR1; local recruitment bypass modifies Q directly. This approximation does not capture spatial recruitment, error correction kinetics, checkpoint silencing or cytokinesis.

Two other proxies remain separate:

`checkpoint_signal = [B_checkpoint / (0.5 + B_checkpoint)] / [1 / 1.5]`

`checkpoint_braking_proxy = checkpoint_signal / APC_exit_capacity`

`exit_capacity_proxy = APC_exit_capacity`

The 0.5 saturation constant is an assumed scale. Stronger braking is not automatically better. At zero exit capacity, braking is undefined and remains missing; the model does not report perfect rescue from permanent arrest. APC/C binding-mode effects, including paradoxical slippage, require a more detailed calibrated model.

Normal tissue is represented by the selected allele scenario. The tumor arm evaluates two hypothetical states: the same residual state, or increased synthesis of residual products by an assumed factor between two and four. No reference tumor allele is invented. These states probe a dependency; they do not establish the tumor's actual expression or genotype. Neither arm contains a fitted viability or clonogenic-survival equation.

Each of four allele scenarios uses 128 Latin-hypercube parameter sets with seed 20261020. The ranges explore uncertainty; their sampling density is not a biological probability distribution. Five target-effect strengths are 0, 0.25, 0.5, 0.75 and 0.95. These are idealized intervention fractions, not drug doses or achievable exposures. Results report deltas from each scenario's own vehicle baseline, with minimum, median and maximum across the sampled parameter sets. Those ranges are not confidence intervals.

A separate drug-response adapter accepts:

`target_effect_fraction = Emax × C_free^Hill / (EC50^Hill + C_free^Hill)`

C_free and EC50 must use the same concentration unit. The profile must identify the exact chemical, target, modeled intervention, functional assay, source and exposure basis. The assay response must correspond to the modeled intervention; enzyme activation cannot be assumed to equal the same fractional change in protein degradation without a justified intermediate relationship. Free exposure may be a labeled scenario, rather than a patient measurement.

A Kd, an unspecified “binder,” or a total-plasma concentration alone does not satisfy this adapter. Missing inputs produce an unresolved record. Synthetic adapter controls remain labeled separately from measured profiles. Each current profile represents one specified drug action; it does not account for the drug's full set of targets.

The catalog audit uses exact human gene mappings and recorded action direction. Complex or indirect records remain contextual. Current approval is not inferred from ChEMBL phase-four status. Quantitative bioactivity acquisition, indirect mechanism mapping, regulatory identity review and biological calibration remain required before promoting a catalog match to a contest nomination.

Reproduce the virtual target experiments from the project root:

```powershell
python -m mva.target_first --output outputs\target_first_replay
```

To supply functional drug-response data, copy and complete `config/target_first_drug_profiles.template.json`, then run:

```powershell
python -m mva.target_first --drug-profiles path\to\completed_profiles.json --output outputs\target_first_drug_replay
```

The runner refuses to overwrite an existing output directory. Core calculations use Python's standard library. calibration_requirements.json in a completed full target-run directory records the experimental quantities and held-out checks needed to move beyond this prototype.
